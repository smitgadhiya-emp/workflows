Title : Supabase Realtime WebSocket Connection Budget Forecaster

Models a Supabase application's realtime WebSocket connection consumption against the plan limits - 500 concurrent connections on Pro, 10,000 on Team - by analyzing the application's subscription patterns. Counts all active supabase.channel() and supabase.from().on() subscription points in the frontend codebase and estimates how many persistent WebSocket connections each active user session holds simultaneously. Identifies the chat-based AI interface pattern where each user holds one persistent WebSocket for real-time responses - meaning the 500-connection Pro limit is hit at exactly 500 concurrent users, not at database CPU limits. Detects subscription fan-out: a realtime dashboard that opens 8 separate channel subscriptions per user session multiplies the connection cost 8× per user. Calculates the user concurrency ceiling per Supabase plan tier and the exact traffic level that triggers the connection wall. Projects the monthly active user count at which the current subscription pattern demands an upgrade from Pro to Team plan. Exports connection budget model to Google Sheets with subscription count per user, concurrent connection ceiling per plan tier, and upgrade trigger threshold.
