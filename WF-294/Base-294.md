Crawls an entire Notion workspace - all databases, pages, linked databases, and wiki nodes - and builds a content inventory by extracting page titles, property schemas, and text block content. Applies semantic similarity analysis across all pages to detect redundant knowledge: the same information maintained in three separate databases with slightly different schemas, the same process documented in four different team wikis with outdated versions of each. Identifies schema drift across linked databases: two databases that were originally synced from the same template but have diverged with different property names for the same logical fields. Maps the single-source-of-truth gaps: information that must be manually kept consistent across 5 Notion locations because no master database drives the others. Calculates the maintenance overhead of each redundancy - hours per month spent keeping duplicate content aligned across locations. Generates a knowledge architecture report in Google Docs with a consolidation plan ranking redundancies by maintenance cost, and exports the full redundancy map to Google Sheets with page URLs, similarity scores, and suggested canonical source per knowledge cluster.
