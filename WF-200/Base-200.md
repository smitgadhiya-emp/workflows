Scans all Next.js Server Action functions (files with use server directive) and for each action verifies the presence of authentication and authorization checks before any business logic or database mutation executes. Identifies patterns where sessions are checked inconsistently: some actions call getServerSession() at the top while sibling actions in the same file perform unauthenticated mutations. Tests for the specific vulnerability where Server Actions are reachable as public POST endpoints with no auth, allowing unauthorized callers to trigger privileged operations. Cross-references each unguarded action against the data it reads or writes to classify severity: an unguarded action that writes to a payment record scores higher than one that reads a public config. Calculates what percentage of the total Server Action surface area has zero auth coverage and which data models are most exposed. Exports the auth coverage matrix to Google Sheets with severity ratings per action.Scan use server actions for missing auth, role checks, CSRF protection, and privileged mutations; rank exposed actions by data sensitivity and exploitability.
