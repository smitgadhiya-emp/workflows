Crawls documentation sites, GitHub READMEs, Stack Overflow tag pages, and official changelog pages for a specific technology stack (e.g., the full MERN stack: MongoDB docs, Express docs, React docs, Node.js docs) to build a unified, cross-referenced knowledge corpus. Extracts structured content with source attribution, version tags, and recency metadata - answers from Node.js 18 docs are tagged as potentially outdated, Node.js 22 docs are tagged as current. Resolves cross-document contradictions by version: when the MongoDB 5.x and 7.x docs give different answers about aggregation pipeline behavior, the chatbot presents both with version context. Builds a query classification layer that routes developer questions to the most relevant documentation subset - "how do I set up auth" routes to Express and JWT docs, not React component docs. Tracks which questions return low-confidence answers (no strong document match) to generate a prioritized list of knowledge gaps where documentation is missing or insufficient. Deploys as a GitHub-linked chatbot that recognizes the project's specific package versions and retrieves version-accurate answers from the matched docs.
