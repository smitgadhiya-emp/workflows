Scans an organization's entire Google Drive - Docs, Sheets, Slides, PDFs - cataloging documents by type, author, modification date, and folder hierarchy to understand the knowledge structure. Extracts text from each file type using appropriate parsers, preserving table data from Sheets, slide context from presentations, and section headings from Docs to maintain retrieval precision. Builds a metadata-enriched vector index in MongoDB where each chunk carries its source document title, author, date, folder path, and document type - enabling retrieval filtered by recency, author, or topic area. Constructs a query routing layer that classifies incoming questions by knowledge domain and routes to the appropriate document subset rather than searching the entire corpus blindly. Detects knowledge gaps - questions where no document covers the topic - and generates a list of documentation that needs to be written. Surfaces answer confidence scores and flags when retrieved documents are older than 90 days and may be outdated.
